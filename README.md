# paper_learning

面向 AI/ML 初学研究生的交互式论文学习技能。以接触过 CS231n、PyTorch、CNN 和 Transformer 为起点，根据论文补前置知识，重点适配计算机视觉、多模态、具身智能/VLA 和世界模型/WAM。

按七个阶段推进：问题定位、创新辨析、方法与张量流、实验与消融、批判性评价、低成本复现规划、实习面试。每轮只教一个阶段或子问题，提出理解问题后等待回答。

## 在 Codex 中使用

发布目录保留 `paper_learning`，frontmatter 中的技能名称为 `paper-learning`，以符合随附本地技能校验器的连字符命名要求。显式调用时使用 `$paper-learning`。

将整个文件夹复制到你的 Codex 技能目录中，例如 `~/.codex/skills/paper-learning/`；保留 `references` 的相对位置。也可以在对话中直接指定本地 `SKILL.md` 的路径并要求遵循它。

附上论文 PDF 或可访问全文，使用：

```text
$paper-learning
请带我逐阶段学习这篇论文。我接触过 CS231n、PyTorch、CNN 和 Transformer，
但不确定是否掌握了本篇所需的前置知识。我的方向是具身智能/VLA，
目标是算法实习。先做问题定位，每轮问我理解问题并等待回答。
```

后续可以说：

- “这条公式没理解，请用张量形状和一个小例子解释，先别进入下一阶段。”
- “我只有一张 8GB 显存的卡、两天时间，请规划能验证一个关键机制的最小实验。”
- “开始面试模拟，一次问一道题。我只读过论文，还没有运行代码。”

没有完整论文时，技能会明确当前可分析的范围。论文特有细节必须有已读材料的页/节/图/表/公式定位；作者主张、原文证据、助手推断和教学示例分别标记。复现计划、实际执行和论文报告的结果分别记录。

## 笔记与 GitHub 发布

需要整理笔记时使用 [Markdown 模板](references/note-template.md)，只填已学习和已核实的部分。不要将模板完整度等同于掌握程度，也不要把计划描述成已完成的复现。

上传到 GitHub 时保留此文件夹结构；仓库根目录或已有 `skills/` 目录均可，按目标仓库约定放置。本包没有预设仓库、分支、许可证，也没有执行远程上传。
